# Work size — when to load Soloship workflow skills

Do the work. Always-on gates still apply.

Load `/soloship:plan`, `/soloship:grill-me`, `/soloship:review`, `/soloship:autoplan`, `/soloship:implement`, `/soloship:deepen-plan`, or `/soloship:shipthorough` only when:

1. the user named that skill, or
2. the work is load-bearing: billing/credit, live customer or financial data, production deploy, auth, or schema/migrations.

Do not chain those skills as a default pipeline. Do not grill, autoplan, or deepen because a plan file exists.
